# Synthetic fixture provenance

Integration media is generated at test time from `fixture_generator.py`.
It contains only a solid black 64×64 video signal and a synthesized 440 Hz
tone, lasts 0.25 seconds, and uses deterministic open codecs. No recorded,
commercial, or third-party media is stored or redistributed.

The generator source is part of de-dolby and is licensed under the same terms
as this repository. Generated files are temporary test artifacts and must not
be committed.
